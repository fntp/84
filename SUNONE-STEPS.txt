========================================
 SunOne 自瞄（ai_5.0.3_CUDA）操作步骤
========================================

拉完代码后就看这个文件。

这个文件管的是 F:\aifz\ai_5.0.3_CUDA 里那套 SunOne 自瞄，
和本仓库的跟随工具是两回事，互不影响。

游戏设置：窗口化跑（你现在就是 1920x1080 窗口化，不用改）。
不要用独占全屏 —— 独占全屏下这个工具抓不到画面。


---- 现在卡在哪 -----------------------------------------------------

症状：准星对着人头时，一会儿往左上跳、一会儿往右上跳，跳得非常快；
倍率压到 0.05 只是把跳的幅度压小了，跳的频率一点没变。

原因（读了源码，不是猜的）：

   这个工具每帧都会拿"上一帧到这一帧目标挪了多少"往前外推一段，
   外推的时间 = predictionInterval + 检测延迟补偿 + 额外预测。

   卡尔曼关掉之后，"挪了多少"就不再是滤波后的速度，而是
   **两帧检测框之间的原始抖动**；而画面那一帧到鼠标真正动之间隔着
   20~50ms，于是每帧都拿这个抖动往前推 20~50ms 的位置。
   下一帧抖动反号，目标点就跳到另一边 —— 表现出来就是"很快地左右来回跳"。
   跳多远由倍率决定，跳的频率是帧率决定的，所以降倍率只会让幅度变小。

要做的是把外推时间彻底变成 0。就差最后这一处：
kalman_compensate_detection_delay（检测延迟补偿），默认是 true。
它一关，lookahead 就是 0，predict() 直接返回当前位置，跳就没了。

   （源码位置，供核对：
     include/aim_kalman.h   predict()  —— lookahead <= 0 时直接 return position()
     mouse/mouse.cpp        currentPredictionLookaheadSec() —— 把检测延迟加进 lookahead
                            currentDetectionDelaySec()      —— 检测延迟 = 这一帧的年龄
     mouse/mouse.cpp        moveMousePivot() 用的是 predict_target_position() 的返回值）


---- 1. 关掉这处外推（PowerShell 整段复制粘贴，回车） ---------------

   $p='F:\aifz\ai_5.0.3_CUDA\config.ini'
   Copy-Item $p "$p.bak3" -Force
   $t = [IO.File]::ReadAllText($p)
   $set = @{'predictionInterval'='0';'kalman_compensate_detection_delay'='false';'kalman_additional_prediction_ms'='0'}
   foreach($k in @($set.Keys)){
     $line = "$k = $($set[$k])"
     $re = '(?m)^\s*' + [regex]::Escape($k) + '\s*=.*$'
     if($t -match $re){ $t = $t -replace $re, $line }
     else { $i = $t.IndexOf("`n["); if($i -lt 0){ $t = $t.TrimEnd() + "`r`n" + $line } else { $t = $t.Insert($i+1, $line + "`r`n") } }
   }
   [IO.File]::WriteAllText($p, $t)
   Get-Content $p | Select-String 'predictionInterval|kalman_compensate_detection_delay|kalman_additional|kalman_enabled|minSpeedMultiplier|maxSpeedMultiplier'

   跑完会打印几行，确认这三行是：

     predictionInterval = 0
     kalman_compensate_detection_delay = false
     kalman_additional_prediction_ms = 0

   如果打印出来本来就是这样，那就说明问题只在
   kalman_compensate_detection_delay 这一行 —— 它原来是 true。

   备份在 config.ini.bak3，改坏了还原：
     Copy-Item F:\aifz\ai_5.0.3_CUDA\config.ini.bak3 F:\aifz\ai_5.0.3_CUDA\config.ini -Force

---- 3. 进游戏试 ---------------------------------------------------

   按住右键、准星对着敌人，看准星怎么走：

   · 不再左右甩了（可能还有点小抖，但不再是"往左一下往右一下"）
       → 对了，这就是根因。接着做第 4 步。
   · 还是很快地左右跳
       → 打开悬浮窗（Home 键），把 Mouse 页里的
         “Enable Kalman Filter”勾上再试一次。

         还是跳就做第 7 步的回报。


---- 4. 不跳了，但瞄准点还差一点点偏上 / 偏下 -----------------------

   这是"瞄准点落在目标哪个位置"的问题，跟倍率、外推都没关系。
   悬浮窗（热键默认是 Home；键盘上没 Home 键的先照"附一"改成 F8）
   → 左侧菜单 **Aim** 分组里点 **Target** 页，往下有两个滑块：

     Approximate Head Y Offset    默认 0.05    ← 打头用这个
     Approximate Body Y Offset    默认 0.15    ← 打身子用这个

   含义：从检测框顶部往下走多少（按框高度的比例）。
   数值越大，瞄准点越往下；越小越往上。

   偏上一点点 → 往大调一档：0.05 → 0.10 → 0.15
                一边拖一边看准星，落到头正中就停手。
   偏下一点点 → 往小调。

   拖滑块当场生效：不用按 F4、不用重启；松手就自动存回 config.ini。

   拖 Head 那个滑块如果一点变化都没有（说明你的模型没在识别"头"这一类框，
   用的是整身框 + Body 偏移），那就改拖 Body 那个。

   同一个页面下面有 Preview 参考图：红线上写着 Body、绿线上写着 Head，
   画的就是这两个数值现在把瞄准点放在人体的哪个高度，可以对着调。

   两头都拖到头（0.00 或 1.00）还差一点点 → 那就不是这个的问题了，
   做第 7 步的回报，把 [Games] 那几行发我。


---- 5. 不蹦了之后：把倍率提上来 ------------------------------------

   之前被迫用 0.05，很大原因就是这个抖 —— 倍率一大，抖动被放大成"跳"。
   现在一档一档往上提：

       0.05 → 0.1 → 0.2 → 0.3

   每档进游戏试：

   · 贴上去稳、不甩         → 再往上提一档，直到刚要冲过头就退回来
   · 慢慢爬、贴不上、跟不上移动的目标 → 太小了，往上提
   · 某一档又开始"很快地左右跳"       → 退回低一档先用着，做第 6 步

   改倍率的命令（两个数填一样，让倍率固定、不随远近变）：

   $p='F:\aifz\ai_5.0.3_CUDA\config.ini'; (Get-Content $p) -replace '^\s*minSpeedMultiplier\s*=.*','minSpeedMultiplier = 0.1' -replace '^\s*maxSpeedMultiplier\s*=.*','maxSpeedMultiplier = 0.1' | Set-Content $p; Get-Content $p|Select-String 'SpeedMultiplier'


---- 6. 只有"怎么调都偏一点"时，才动 [Games] ------------------------

   先别动这一步，把第 7 步的回报发我。

   SunOne 认为"1 个鼠标计数 = 游戏转多少度"，写在 config.ini 的 [Games] 里：

     UNIFIED = 1,0.022,0.022        ← 名字 = 灵敏度, yaw, pitch

   0.022 是 CS 的标定值，跟别的游戏差好几倍。它同时决定两件事：
   算"该推多少鼠标"，以及"我自己刚才的移动把画面挪了多少"的自我补偿。
   标定对不上时，补偿会多补/少补 —— 表现就是：怎么调倍率都偏一点，
   或者倍率一提就抖。真要改就是 yaw/pitch 乘几倍、倍率同时乘几倍
   （保持手感不变），具体数值我按你的游戏和 DPI 给你算，比一档档试快。

   把 [Games] 那几行发我用这条命令：

   $p='F:\aifz\ai_5.0.3_CUDA\config.ini'; Get-Content $p | Select-String '^active_game|^\[Games\]' -Context 0,6

---- 附一：悬浮窗怎么开 ---------------------------------------------

   悬浮窗（改参数的图形窗口）**默认是关着的**，要按热键才出来。
   这个热键写在 config.ini 里，叫 button_open_overlay，出厂值是 Home。

   键盘上没有 Home 键（笔记本多半没有）→ 把热键换成 F8：

   $p='F:\aifz\ai_5.0.3_CUDA\config.ini'

   $t = [IO.File]::ReadAllText($p)
   $re = '(?m)^\s*button_open_overlay\s*=.*$'
   $line = 'button_open_overlay = F8'

   else { $i = $t.IndexOf("`n["); if($i -lt 0){ $t = $t.TrimEnd() + "`r`n" + $line } else { $t = $t.Insert($i+1, $line + "`r`n") } }
   [IO.File]::WriteAllText($p, $t)
   Get-Content $p | Select-String 'button_open_overlay'

   打印出 button_open_overlay = F8 就对了（备份在 config.ini.bak4）。
   然后回 ai.exe 那个黑窗口按一下 F4（重载配置），再按 F8 —— 悬浮窗就出来。
   不放心就关掉 ai.exe 重开。悬浮窗是个左上角的小窗口，出来时在最前，
   可以拖到一边，改完参数不用关它。

   （有 Home 键的话不用改，直接按 Home；Home 一般在方向键上方那一排
   Ins / Del / Home / End / PgUp / PgDn 六个键里，笔记本没有独立 Home
   键的话是 Fn + Home。）

   实在不想开悬浮窗也行：要改的每个数值都能直接改 config.ini，改完按 F4 生效
   —— 只是不能边瞄边看效果。例：把打头的瞄准点往下挪一档（head_y_offset

---- 附三：好几个人同框时，老是换目标 -------------------------------

   能不能固定打一个？能。要做的不是找什么"锁定"开关，而是
   **不让别人进识别范围**。

   先说清楚它本来是怎么工作的：
   这个工具一直有锁定（Tracker），config.ini 里 tracker_enabled 默认就是
   true，而且**按住右键（瞄准键）期间锁是保持的** —— 只要锁定的人还在被
   识别到，它就不会换人。

   换人只有一个触发点，而且是写死的：
   锁定的人连续约 15 帧（60fps 下约 0.25 秒）完全没被识别到 → 锁被丢掉 →
   立刻改选"离准星最近的那个人"。
   所以被打的人只要被掩体挡住、跑出识别范围、或者模型漏检超过 0.25 秒，
   就会跳到旁边那个人身上。这个帧数写在源码里（maxMissedFrames = 6，
   锁定目标再加 8），config.ini 改不了，只能绕。

   ------------------------------------------------
    办法：把识别范围缩小（推荐，能边打边调）
   ------------------------------------------------

   悬浮窗 → 左侧 **Vision** 分组 → **Capture** 页，往下看：

     Circle FOV          勾选框，默认已开
     Circle FOV size     滑块，默认 100%   ← 拖小它

   含义：只认"以准星为圆心、这个百分比为半径"的圈里的目标，检测框的
   中心落在圈外的人，直接不算数。圈越小，旁边的人越进不来。

     100%  = 现在这样，整个识别范围都算
     70% / 50% / 30%  一档一档往小拖，边打边看
     ~30%  基本只有准星正指着的那个人会被识别到

   别拖过头：拖太小会把正在打的人也筛掉（框中心也得在圈里），表现是
   "打着打着目标突然丢一下"。出现丢目标就说明拖太小了，往回加一档。

   （识别范围本身就是以准星为中心的一个正方形，边长由 Capture 页的
     Detection Resolution 决定，默认 320 像素；Circle FOV 是在这个正方形
     里面再收一次圈。所以 30% 大约是准星周围 96×96 像素的范围。）

   想看见这个圈：Visuals 分组 → **Game Render** 页把 `Enable` 勾上，
   再到 **Render Style** 页，Capture Frame 那一块里把 `Draw Circle Guide`
   勾上，游戏里就会画出这个圈，对着圈调最方便。

   ------------------------------------------------
    两个配套注意点
   ------------------------------------------------

   · **要一直按住右键。** 松开右键时每一帧都重新挑"离准星最近的"，
     松手再按就会换人。不想一直按 → Aim 分组 → **Target** 页，
     把 `Auto Aim` 勾上（等于一直按着）。
   · **别**去 Aim → **Tracker** 页把 `Enable Tracker` 关掉。关掉就完全
     不锁定了，每一帧都重挑最近的人，换得比现在更勤。

   ------------------------------------------------
    不开悬浮窗就直接改（改完按 F4）
   ------------------------------------------------

===== 从这里开始复制 =====
$p='F:\aifz\ai_5.0.3_CUDA\config.ini'
Copy-Item $p "$p.bak6" -Force
$t = [IO.File]::ReadAllText($p)
$set = @{'circle_fov_enabled'='true';'circle_fov_radius_percent'='30'}
foreach($k in @($set.Keys)){
  $line = "$k = $($set[$k])"
  $re = '(?m)^\s*' + [regex]::Escape($k) + '\s*=.*$'
  if($t -match $re){ $t = $t -replace $re, $line }
  else { $i = $t.IndexOf("`n["); if($i -lt 0){ $t = $t.TrimEnd() + "`r`n" + $line } else { $t = $t.Insert($i+1, $line + "`r`n") } }
}
[IO.File]::WriteAllText($p, $t)
Get-Content $p | Select-String 'circle_fov'
