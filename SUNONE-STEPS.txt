========================================
 SunOne 自瞄（ai_5.0.3_CUDA）操作步骤
========================================

拉完代码后就看这个文件。

这个文件管的是 F:\aifz\ai_5.0.3_CUDA 里那套 SunOne 自瞄，
和本仓库的跟随工具是两回事，互不影响。

游戏设置：窗口化跑（你现在就是 1920x1080 窗口化，不用改）。
不要用独占全屏 —— 独占全屏下这个工具抓不到画面。

当前进度：抓屏已经好了（控制台不再刷 [DDA] DuplicateOutput failed），
预测和卡尔曼也已经关掉了。现在准星贴着目标时还是一会儿往左上跳、
一会儿往右上跳，跳得很快 —— 这是"每帧推出去的鼠标量太大"，
一下跨过了目标，下一帧又从对面跨回来，看起来就是左右来回蹦。

所以现在要做的事只有一件：把倍率再往下压。先压到 0.05。

调倍率的规矩（来回试几次就到了）：
  还跳得很快  → 再降 ：0.05 → 0.02
  变成慢慢爬过去、贴上就不动 → 方向对了，再往上提：0.02 → 0.05 → 0.1 → 0.2
  提到刚好快要冲过头，就退回去一档，那就是这台机器/这个游戏合适的量。


---- 1. 改倍率（PowerShell 里整行复制粘贴，回车） -------------------

   两个 0.05 就是你要的倍率，改数值就改这两处。

$p='F:\aifz\ai_5.0.3_CUDA\config.ini'; (Get-Content $p) -replace '^\s*minSpeedMultiplier\s*=.*','minSpeedMultiplier = 0.05' -replace '^\s*maxSpeedMultiplier\s*=.*','maxSpeedMultiplier = 0.05' | Set-Content $p; Get-Content $p|Select-String 'SpeedMultiplier'

   跑完打印两行，确认一下：

     minSpeedMultiplier = 0.05
     maxSpeedMultiplier = 0.05

   这两个是"每帧真正推出去的鼠标量 = 算出来的量 × 这个系数"。
   两个值填成一样，是为了让倍率固定，不随离目标远近变 —— 调起来才准。


---- 2. 让新配置生效 -----------------------------------------------

   ai.exe 还在跑的话，按一下键盘上的 F4（重载配置），不用重启。
   不放心就关掉重开：

cd F:\aifz\ai_5.0.3_CUDA
.\ai.exe

   起来会打印那几行热键（右键瞄准 / F2 退出 / F3 暂停 / F4 重载配置）。
   控制台里不应该再出现 [DDA] DuplicateOutput failed。


---- 3. 进游戏试 ---------------------------------------------------

   进游戏，找个敌人，准星对着他，按住鼠标右键别松，看准星怎么走。

     · 慢慢贴上去、贴上就不动了
         → 对了。回第 1 步把 0.05 往上提一档（0.1），再试；
           提到刚要冲过头就退回去，那个值就是这台机器的上限。
     · 冲过头再飞回来、来回蹦
         → 还是偏大。回第 1 步把两个 0.05 改成 0.02，再试。
     · 还在原地绕圈、或者完全不动
         → 把第 4 步那几件事发我，我按你的游戏算该填多少。


---- 4. 回报 -------------------------------------------------------

   回来告诉我这几件事：

     1. 现在是什么现象？慢慢贴 / 来回蹦 / 绕圈 / 完全不动？
     2. 倍率填的是多少（0.05 还是 0.02）？
     3. 什么游戏？游戏内灵敏度多少？（不知道灵敏度就说 cm/360）
     4. 鼠标 DPI 多少？
     5. Mouse → Input Method 里现在选的是什么（WIN32 / KMBOX_NET / MAKCU …）。

   第 3、4 项是关键：SunOne 里真正决定"1 个鼠标计数游戏转多少度"的，
   是 config.ini 里 [Games] 那一行的 yaw / pitch，默认 0.022 是 CS 的值，
   跟你游戏多半差好几倍。有了游戏名 + 灵敏度 + DPI，我可以直接算出该填的数，
   比一档一档试着调准得多。


---- 附一：悬浮窗怎么开 ---------------------------------------------

   悬浮窗（就是改参数的图形窗口）是 ai.exe 起来之后，按键盘上的 Home 键。

   不是 Windows 键。Home 一般在方向键上方那一排（Ins / Del / Home / End /
   PgUp / PgDn 六个键里的一个）；笔记本上没有独立 Home 键的话按 Fn + Home。

   上面第 1 步是直接改文件，不开悬浮窗也一样能改。


---- 附二：还原 / 查当前配置 ----------------------------------------

   整份配置还原（如果一开始备份过）：

cd F:\aifz\ai_5.0.3_CUDA
Copy-Item .\config.ini.bak .\config.ini -Force

   看现在这几个值是多少：

$p='F:\aifz\ai_5.0.3_CUDA\config.ini'; Get-Content $p|Select-String 'fovX|fovY|SpeedMultiplier|prediction|kalman|active_game|^\[Games\]|^\S+\s*=\s*\d+\.?\d*,\d'
