========================================
 SunOne 自瞄：按 F8 打开面板，照下面做
========================================

下面每一段代码都有"从这里开始复制 / 复制到这里结束"的标记，
一次只复制中间那一段，整块贴进 PowerShell 回车。


--------------------------------------------------------------
 现在先做这一件：把面板改回 10 月 2 号晚上最后那套设置
--------------------------------------------------------------

不用还原文件、不用跑脚本。按 F8 打开面板，对着下面一项一项改。
（没列到的项**都别动**。）

  Aim → Target
    Disable Headshot                   不勾  ← 最要紧，勾上就只打身子不打头
    Auto Aim                           不勾
    Approximate Head Y Offset          0.10
    Approximate Body Y Offset          0.15

  Aim → Movement
    FOV X                              90
    FOV Y                              60
    Min Speed Multiplier               0.1
    Max Speed Multiplier               0.1
    Snap Radius                        拖到最小
    Snap Boost Factor                  1.0
    Near Radius                        25.0
    Speed Curve Exponent               3.0

  Aim → Prediction
    Enable Kalman Filter               不勾
    Prediction Interval                0.00
    Kalman Compensate Inference Delay  不勾
    Kalman Additional Predict (ms)     0.0
    （这三个都对时，这一页会有一行红字 Prediction is disabled. 是正常的）

  Vision → Capture
    Circle FOV                         勾上
    Circle FOV size                    38

  Vision → AI Model
    Confidence Threshold               0.10

改完按一下 F4（面板里拖的当场就生效，按一下更保险）。

两处说明（先照上面填，别纠结）：

  · Min / Max Speed Multiplier
      10 月 2 号晚上这两个值是直接改文件设成 0.05 的，面板上的滑块最小
      只能到 0.1，所以面板里填 0.1。要精确回到 0.05 得改文件，需要的话
      说一声，我给你一行命令。
  · FOV X / FOV Y
      10 月 2 号晚上最后是 90 / 60。如果面板上现在显示 106 / 74，那是
      程序自带的默认值，不是你要的那套，按 90 / 60 填。

另外：Snap Radius / Snap Boost Factor 这两个，在 Min 和 Max 填一样的时候
本来就不起任何作用（速度恒等于那个倍率，进不进那个圈都一样），填回去只是
为了跟那晚完全一致，不用管它俩。


--------------------------------------------------------------
 第一步（做过了）：把悬浮窗热键从 Home 改成 F8
--------------------------------------------------------------

悬浮窗（改参数的图形窗口）默认是关着的，要按热键才出来，
热键出厂值是 Home。键盘上没有 Home 键就永远按不出来，所以先改成 F8
（F1-F12 哪个键盘都有；F2 / F3 / F4 已经被"退出 / 暂停 / 重载"占了）。

===== 从这里开始复制 =====
$p='F:\aifz\ai_5.0.3_CUDA\config.ini'
Copy-Item $p "$p.bak4" -Force
$t = [IO.File]::ReadAllText($p)
$re = '(?m)^\s*button_open_overlay\s*=.*$'
$line = 'button_open_overlay = F8'
if($t -match $re){ $t = $t -replace $re, $line }
else { $i = $t.IndexOf("`n["); if($i -lt 0){ $t = $t.TrimEnd() + "`r`n" + $line } else { $t = $t.Insert($i+1, $line + "`r`n") } }
[IO.File]::WriteAllText($p, $t)
Get-Content $p | Select-String 'button_open_overlay'
===== 复制到这里结束 =====

跑完会打印一行：

  button_open_overlay = F8

看到它就成了（原文件备份成 config.ini.bak4）。

接着做：

  1. 回 ai.exe 那个黑窗口，按一下 F4（重载配置）。不放心就关掉重开。
  2. 按 F8 —— 悬浮窗出来。是个左上角的小窗口，出来时在最前面，
     可以拖到一边，不用关它。
  3. 悬浮窗左侧竖排菜单里，找到 **Aim** 分组，点里面的 **Target** 页。

     进去从上往下看，是这些东西：

        两个勾选框   Disable Headshot / Auto Aim
        两行黄字     Arrow keys: Adjust body offset
                     Shift+Arrow keys: Adjust head offset
        两行滑块     Approximate Body Y Offset     0.15   ← 打身子用
                     Approximate Head Y Offset     0.05   ← 打头改这个
        一张人体图   红线上写 Body、绿线上写 Head，画的就是这两个值
                     现在把瞄准点放在人体哪个高度

     （"Offsets" 只是代码里的分组名，界面上不显示这几个字，
       认滑块名字 Approximate Head Y Offset 就行。）

     把 Approximate Head Y Offset 的滑块往右拖，数值变大：0.05 → 0.10 → 0.15，
     边拖边看准星，落到头正中就松手。数值越大 = 瞄准点越往下。

     0.05 到 0.10 距离很小不好拖，可以按住 Ctrl 再用左键点一下那个滑块，
     会弹出一个直接输数字的框，打 0.10 回车。

     拖动当场生效，不用按 F4；松手就自动存回 config.ini。


--------------------------------------------------------------
 第二步（不想开悬浮窗才用）：直接改瞄准点高度
--------------------------------------------------------------

===== 复制到这里结束 =====

打印出 head_y_offset = 0.10 就成了，然后按 F4。还偏上就再改成 0.15，
改过头偏下了就改回 0.05。数值越大，瞄准点越往下。

（0.05 是"头的检测框顶部往下 5%"，基本就是头顶，所以默认会偏上一丁点。
 打身子用的是另一个值 body_y_offset，默认 0.15，一般不用动。）

 第三步：人多的时候老在几个人之间换目标（缩小识别圈）
--------------------------------------------------------------

面板上改最方便（能边打边调）：左侧 **Vision** 分组 → **Capture** 页 →
`Circle FOV size` 滑块，默认 100%，往小拖到 30% 左右
（只认准星周围一小圈里的目标，旁边的人就进不来了）。

不想开面板就直接改 config.ini（改完按 F4）：

$p='F:\aifz\ai_5.0.3_CUDA\config.ini'

还换人就往下改小，开始丢目标就改大。

--------------------------------------------------------------
 第四步：想调得更平滑（Prediction 页 / 卡尔曼）
--------------------------------------------------------------

面板上调最直观：左侧 **Aim** 分组 → **Prediction** 页。

这页上面三个是"往前猜"（抖的来源），现在是关着的，别开回来：

  Prediction Interval                0.00
  Kalman Compensate Inference Delay  不勾
  Kalman Additional Predict (ms)     0.0

下面整段是卡尔曼滤波。**卡尔曼关着的时候，程序用的是原始检测框位置，
一点平滑都没有**；开着它 = 只平滑、不往前猜，能把小抖动抹平。

想把配置改成"平滑版"（开着卡尔曼、外推仍为 0）：

===== 从这里开始复制 =====
$p='F:\aifz\ai_5.0.3_CUDA\config.ini'
Copy-Item $p "$p.bak7" -Force
$t = [IO.File]::ReadAllText($p)
$set = @{'kalman_enabled'='true';'predictionInterval'='0';'kalman_compensate_detection_delay'='false';'kalman_additional_prediction_ms'='0'}
foreach($k in @($set.Keys)){
  $line = "$k = $($set[$k])"
  $re = '(?m)^\s*' + [regex]::Escape($k) + '\s*=.*$'
  if($t -match $re){ $t = $t -replace $re, $line }
  else { $i = $t.IndexOf("`n["); if($i -lt 0){ $t = $t.TrimEnd() + "`r`n" + $line } else { $t = $t.Insert($i+1, $line + "`r`n") } }
}
[IO.File]::WriteAllText($p, $t)
Get-Content $p | Select-String 'kalman_enabled|predictionInterval|kalman_compensate_detection_delay|kalman_additional'
===== 复制到这里结束 =====

打印出 `kalman_enabled = true`、另外三个是 0 / false / 0 就成了
（备份 config.ini.bak7）。按 F4 重载。

平滑程度不用改文件 —— 在 Prediction 页里拖这两个滑块，拖着就生效：

  Kalman Measurement Noise   默认 35     往大拖：80 → 150 → 300（更平滑）
  Kalman Velocity Damping    默认 0.08   往大拖：0.2 → 0.4 → 0.8（更稳）

觉得太肉、跟不上人，就往回拖。一次只动一个，动完打一会儿再动下一个。
其余 Kalman 开头的滑块一般不用碰。各参数含义看 SUNONE-STEPS.txt 的"附五"。
